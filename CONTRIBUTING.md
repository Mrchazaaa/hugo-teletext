# Contributing

This repository is a Hugo theme, so preview it from a Hugo site that uses the theme (such as [hugo-teletext-demo](https://github.com/Mrchazaaa/hugo-teletext-demo)).

Start the local development server from the site root:

```bash
hugo server
```

Hugo will print a local URL, usually `http://localhost:1313/`, and reload changes as you edit the theme files.
